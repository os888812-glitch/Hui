как установить

1. установи python 3.11 или новее.

2. распакуй архив в любую папку.

3. открой powershell в папке бота и выполни:
py -3.11 -m venv .venv
.\.venv\scripts\activate.ps1
python -m pip install -r requirements.txt

4. скопируй файл .env.example в .env.

5. открой .env и вставь токен своего бота в строку bot_token.
токен можно получить у @botfather.

6. если нужно, оставь allow_audio_downloads=true, чтобы бот отправлял музыку файлами.

7. запусти бота:
python -m sc_telegram_clone.bot

что умеет бот

бот ищет музыку в soundcloud по обычному тексту от 3 символов.
кнопка скачать отправляет 5 треков текущей страницы одним блоком.
кнопка песни открывает меню песен, альбомов и плейлистов.
при старте бот отправляет 5-й стикер из набора heartballoons.
короче говоря бот полная копия бота @loaditbot
